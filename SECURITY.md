# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

LANFlixx is designed for private local network (LAN / Wi-Fi) streaming. If you discover a security issue (such as directory traversal or remote code execution vulnerability), please report it responsibly:

1. **Email the maintainer**: Contact Ratnadeep Parya at `parya.ratnadeep125@gmail.com`.
2. Please do not disclose vulnerabilities publicly until a fix has been released.
3. Include detailed steps or a proof of concept to help reproduce the issue.
